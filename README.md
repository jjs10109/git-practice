# Git Practice

Continuous Integration - Martin Fowler
https://martinfowler.com/articles/continuousIntegration.html

I found this article interesting because it explains how developers can work together on the same project without waiting too long to combine their code. By integrating changes frequently, teams can find bugs and conflicts earlier instead of dealing with many problems at the end.

I also think this is useful because Git and GitHub make this kind of workflow much easier. Since software projects often involve multiple developers working on different features, learning how to integrate and test changes regularly seems like an important part of software engineering.
